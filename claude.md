## 已实现的核心文件

### 服务层
- `TfsConnectionService` - TFS 连接服务接口
- `TfsConnectionServiceImpl` - TFS 连接服务实现
- `TfsServerConfiguration` - 服务器配置持久化存储

### 向导
- `ImportProjectWizard` - 导入项目向导主类
- `ImportProjectContext` - 向导上下文数据
- `ServerSelectionStep` - 服务器选择步骤
- `TeamProjectSelectionStep` - 团队项目选择步骤
- `ProjectSelectionStep` - 项目选择步骤


## 向导

### 第一步
```
显示 ui
begin
------------------------------------------
|  从 Team Foundation Server 导入项目   [X]|
|----------------------------------------|
|  服务器选择                              |
|    选择要连接到的服务器                    |
|----------------------------------------|
|                                        |
|  TFS服务器：[下拉框        ]    [服务器...]|
|                                        |
|----------------------------------------|
| [上一步](禁用) [下一步]   [完成](禁用) [放弃]|
-----------------------------------------|
end

点击 [服务器...] 按钮 后显示 ui
begin
------------------------------------------
| 添加/移除 Team Foundation Server      [X]|
|----------------------------------------|
|  Team Foundation Server 列表            |
|  [table head               ]  [添加...] |            
|  [table row1               ]  [输入凭证] | 
|  [table row2               ]  [清除凭证] |
|  [table row3               ]  [移除]    |  
|----------------------------------------|
|                                   [关闭]|
-----------------------------------------|
end

注： table 有两列：名称|服务器。由 [添加...] 按钮中输入

点击  [添加...] 按钮
begin
------------------------------------------
| 添加 Team Foundation Server          [X]|
|----------------------------------------|
|  Team Foundation Server 的名称或URL      |
|  [input]                               |
|--连接信息--------------------------------|
|  路径: [input] (填入默认值: tfs)          |
|  端口号: [input] (填入默认值: 8080)        | 
|  协议: [redio(HTTP)] [redio(HTTPS)]     |  
|----------------------------------------|
| 预览: [input] (只读)  [测试]             |
|----------------------------------------|
|                   [输入凭证] [确定] [关闭]|
-----------------------------------------|
end
注：需要测试连通后才能保存

点击  [输入凭证] 按钮
begin
------------------------------------------
| 输入密码                              [X]|
|----------------------------------------|
|  输入 {完整TFS url} 的密码                |
|  凭证类型: [redio(用户/密码)] [redio(个人访问令牌-所有访问范围)]|
|  用户名: [input]                        |
|  密码: [input]                          | 
|----------------------------------------|
|                   [输入凭证] [确定] [关闭]|
-----------------------------------------|
end

注：选择 个人访问令牌 时， 用户名输入框 不可编辑

点击  [清除凭证] 按钮
begin
------------------------------------------
| 清除保存的凭据                         [X]|
|----------------------------------------|
| 是否要清除Team Foundation Server {服务Name} 的已保存凭据|
|----------------------------------------|
|                             [确定] [关闭]|
-----------------------------------------|
end

点击  [移除] 按钮
begin
------------------------------------------
| 移除 Team Foundation Server          [X]|
|----------------------------------------|
| 是否要移除Team Foundation Server {服务Name}|
|----------------------------------------|
|                             [确定] [关闭]|
-----------------------------------------|
end
```
